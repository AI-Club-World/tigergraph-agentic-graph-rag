current description of the system; the current docs are the repository `README.md` and
`docs/round-2/`.

|---|---|
| `round-1/` | `SCORE-AUDIT.md`: self-audit of the Round-1 system against that round's rubric, with the root-cause fixes and before/after scores. |
| `round-2-exploration/` | Notes from before and just after the Round-2 brief arrived: a gap analysis, the first (speculative) plan and requirements, decision notes, and an earlier offline results log. Some of it describes a claim-resolution layer that is still in the code (`reasoning/`, `harness/`) but is not on the Round-2 answering path. |
